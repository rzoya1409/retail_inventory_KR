Retail Inventory Knowledge Repository

Rule-Based Inventory and Reorder Management System

About the System

This project is a cloud-based knowledge repository for a Retail Inventory and Reorder Management System. It uses business rules to support inventory decisions.

Business Decisions Supported

  • Urgent reorder recommendations
  • Low-stock alerts
  • Expired and near-expiry product alerts
  • Slow-moving product identification
  • Fast-moving product stock recommendations

Example Rule

IF current_stock <= reorder_level THEN place a purchase order.

Repository Files

  • knowledge_base.json — Stores business rules
  • inventory_advisory.py — Applies the rules
  • README.md — Project documentation
  • sample_output.txt — Sample execution output

Educational Disclaimer

This is an educational prototype. Real retail systems should include demand forecasting, supplier lead-time analysis, sales history, costs, and profit margins.
